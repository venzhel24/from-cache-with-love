Уровни кеширования

CPU / ОС / Диск

  • L1/L2/L3 кеш
  • Page cache, buffer cache
  • Задачи: ускорение операций

DNS-кеш

  • Кеш IP-адресов
  • Resolver: локальный, облачный
  • Задача: ускорение DNS

CDN

  • Статика: JS, CSS, images
  • Примеры: Cloudflare, CloudFront, Яндекс.CDN
  • Edge — сокращение RTT

Reverse Proxy

  • HTTP-ответы целиком
  • Nginx, Varnish
  • Задача: разгрузка бэкенда

Браузерный кеш

  • HTTP Cache-Control, ETag
  • localStorage, sessionStorage
  • Service Workers (PWA)

Кеш на уровне приложения

Bitrix: типы кеша

  • Управляемый кеш (managed)
  • Неуправляемый кеш (unmanaged)
  • Тегированный кеш (tagged)
  • Кеш компонентов, шаблонов
  • Кеш ORM, API

Symfony: типы кеша

  • Кеш роутов, конфигов, сервисов
  • HTTP-кеш (Etag, Vary)
  • Doctrine: L2 кеш (tagged)

  • Кеш контейнера (DI)

Next.js: типы кеша

  • SSG (Static Site Generation)
  • ISR (Incremental Static Regeneration)
  • Edge Cache (на CDN)
  • Revalidate tags (tagged)
  • Client-side: React Query, SWR

Стратегии кеширования

Cache-aside (Lazy Loading)

  • Приложение проверяет кеш
  • При промахе — читает из источника
  • Записывает в кеш

Read-through

  • Приложение запрашивает данные
  • Кеш сам читает из источника при промахе
  • Кеш кэширует ответ

Write-through

  • Запись одновременно в кеш и источник
  • Гарантия согласованности
  • Высокая нагрузка на запись

Write-behind (Write-back)

  • Запись только в кеш
  • Асинхронная запись в источник
  • Риск потери данных

Refresh-ahead (Prefetch)

  • Обновление кеша до истечения TTL
  • Снижение latency
  • Требует прогнозирования

Cache warming

  • Предзаполнение кеша при старте
  • Для критичных данных
  • Снижает нагрузку на холодный старт

Инвалидация

Инвалидация

  • По времени (TTL)
  • По событию (data change)
  • Tag-based (зависимости)
  • Ручная (manual)

Типовые Ошибки

  • Cache stampede
  • Hot keys
  • Thundering herd
  • Memory leak
  • Stale data

Мониторинг и безопасность

Метрики

  • Hit/miss rate
  • Latency, throughput
  • Memory usage, eviction rate

Безопасность

  • Isolation (multi-tenant)
  • Cache poisoning
  • PII минимум
  • Encryption

Когда НЕ кешировать

  • Часто меняющиеся данные
  • Персонализированный контент
  • Критичные по актуальности
  • Редко запрашиваемые

Тренды

  • Serverless
  • Адаптивные TTL
